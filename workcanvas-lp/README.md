## 更新手順（AI秘書に「WC共有シート更新して」で依頼）

1. マスタ⑤強化エリア・④採用者フォロー・ダッシュボード・**原稿修正案（募集要項の確定表記）・nicotto原稿**、共有シート「各業態の募集,概要」「ご紹介者様」を再取得
2. `src/snapshots/` の前回スナップショットと突合して差分を抽出
3. ★更新サマリタブの「今回の変更点」「強化エリア一覧」「成約者」「店舗一覧」を書き換え
4. index.html（hero統計・サマリ・店舗テーブル・紹介実績）を更新
5. 紹介一覧に変化があれば src/referrals-src.html を更新し再暗号化:
   `npx -y staticrypt src/referrals-src.html -p <パスワード> --short -d src/out --remember 30 --template-title "ご紹介一覧（関係者限り）" --template-instructions "ワークキャンバス様向けのパスワード保護ページです。共有されたパスワードを入力してください。" --template-button "開く" --template-color-primary "#3e5c47"`
   → `cp src/out/referrals-src.html referrals.html`
6. リンク検証: `node src/link-check.mjs`（404や店名不一致がないか）
7. デプロイ: `vercel deploy --prod --yes --scope kojisaito0320`
8. 新しいスナップショットを `src/snapshots/` に保存
